# Employee Management System

## Project Overview

The Employee Management System is a C# console application designed to manage employee information. The project demonstrates fundamental C# programming concepts, object-oriented programming, CRUD operations, LINQ, collections, and input validation.

Employee information is currently stored in memory using a `List<Employee>`.

## Features

- Add a new employee
- View all employees
- Search for an employee by Employee ID
- Update employee information
- Remove an employee
- Calculate an employee's monthly salary from annual salary
- Prevent duplicate Employee IDs
- Validate Employee ID and salary input
- Handle invalid menu selections

## C# Concepts Demonstrated

- Object-Oriented Programming (OOP)
- Classes and objects
- Properties and constructors
- `List<T>` collections
- LINQ
- Lambda expressions
- `FirstOrDefault()`
- `Any()`
- `TryParse()` input validation
- `if / else if / else`
- `while` loops
- `foreach` loops
- String interpolation

## How to Run

1. Open the project in Visual Studio.
2. Build the project.
3. Run the application.
4. Select an option from the Employee Management System menu.
5. Follow the prompts to manage employee information.
